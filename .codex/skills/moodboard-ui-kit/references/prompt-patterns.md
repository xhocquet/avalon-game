# Prompt Patterns

Use these as starting points. Replace bracketed placeholders with image-specific details.

## Background Tile

```text
Create a seamless [setting] background tile for a whimsical fantasy game. Use [palette] with warm paper undertones, medium-thickness dark outlines, crisp cartoon line art, solid flat fills, and clean cel-style separation between shapes. Include [motifs]. Keep it flat, graphic, and game-readable. Ask for transparent background if possible and keep edge composition usable for tiling. Avoid watercolor bloom, gouache texture, painterly shading, realism, blurry edges, glossy gradients, and corporate UI polish.
```

## Prop Sheet

```text
Generate a prop sheet for a strange fantasy game with [props]. Use bright candy colors, soft chunky silhouettes, subtle paper texture, medium dark outlines, crisp 2D cartoon edges, and flat graphic fills. Arrange the props like preproduction snippets with breathing room between items. Request transparent background output if supported. Avoid watercolor, soft painterly texture, heavy rendering, realistic materials, and fuzzy edges.
```

## Border / Sticker Pack

```text
Design a set of doodled UI borders, sticker shapes, swirls, icons, and warning marks for a surreal fantasy game. Use mostly black ink on warm paper with selective pops of [palette accents]. Favor sharp cartoon silhouettes, flat sticker-like rendering, and uneven expressive linework. Isolate the assets with breathing room and request transparent background output if possible. Avoid watercolor wash, airbrushed shading, realism, and soft paint edges.
```

## If The Output Feels Too Painterly

Append language like:

```text
crisp cartoon line art, solid flat fills, cel-shaded feel, clean shape separation, no watercolor, no gouache, no painterly texture, no soft brush rendering
```

## If The Output Feels Too Clean Or Corporate

Append language like:

```text
slightly uneven hand-inked lines, playful wobble, children’s-book energy, hand-drawn imperfections, expressive shapes, preproduction concept-board feel
```
