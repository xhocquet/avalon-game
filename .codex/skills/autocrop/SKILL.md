# Autocrop

Trim excess background from images by calling `autocrop.ps1`, then move originals to `trash/`.

## Background Type

Default to `grid` (Gemini) unless the user specifies a different type. Only ask if the image clearly isn't Gemini-generated and no type was provided.

| Type | Description | Fuzz |
|------|-------------|------|
| `grid` | Gemini checkerboard — two alternating grey shades (varies by export; gap up to ~24%). The Gemini watermark sparkle sits in the bottom-right corner and must be masked before trimming that edge. | 35% |
| `transparent` | PNG or WebP with an alpha-channel background (checkerboard preview in image editors means the file has alpha, not necessarily Gemini's grey grid). | 0% |
| `solid` | Uniform solid color background. | 10% |

**grid vs transparent:** If the image was generated by Gemini AND the checkerboard is baked into the pixel data (not real alpha), use `grid`. If the file has a true alpha channel, use `transparent`.

## Workflow

### Step 1: Call the script for each file

```powershell
& "C:\Users\meesles\.claude\skills\autocrop\autocrop.ps1" `
    -File "C:\full\path\to\image.webp" `
    -Background grid
```

The script performs three passes internally:
1. **Trim top** — dry-run `-trim` to measure Y offset, then `-chop` that many rows from top
2. **Trim left** — same, chops columns from left
3. **Mask + trim bottom/right** — paints bottom-right 100×100 with the background color (neutralizes Gemini watermark), then `-trim` removes remaining bottom and right border

After trimming, it moves the original to `trash/` and renames the cropped output to the original filename.

### Step 2: Report results

For each file, relay what the script printed:
- Original dimensions → final dimensions
- Pixels removed per axis
- Background mode used
- Confirmation original is in `trash/`

If the script reports no dimension change, the file had no trimmable border — leave it and tell the user.

## Notes

- Process multiple files sequentially, one script call per file.
- Do not change file format — `.webp` stays `.webp`, `.png` stays `.png`.
- The `trash/` folder is gitignored.
